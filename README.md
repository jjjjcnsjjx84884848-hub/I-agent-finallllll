# Job Agent for iPad

A free-first Streamlit dashboard that:

- scans configured RSS/Atom sources and the official Remote OK JSON feed;
- ranks jobs and flags scam indicators;
- prepares proposals, client replies, order drafts, and quality checks with Gemini;
- runs hourly with GitHub Actions;
- remains usable without an AI key for basic proposal templates.

The project deliberately does **not** auto-submit applications, bypass CAPTCHAs, impersonate a human, or handle money. Those actions can violate platform rules or cause account blocks.

See `SETUP_IPAD_RU.md` for the iPad installation guide.
